# GoKo Safari — "The Classic Safari & Falls Experience" redesign

A cinematic luxury reimagining of
https://gokosafari.com/package/victoria-falls-to-greater-kruger-safari/

Static site, no build step.

| File | What it is |
|---|---|
| `index.html` + `home.css` + `home.js` | **Homepage (landing)** — mirrors every section and function of gokosafari.com (nav with Destinations dropdown, hero, Beyond Itineraries pillars, Travel Your Way tiles, four destination cards, packages with working Destination / Duration / Style filters, testimonial slider, full Plan Your Safari inquiry form, five-column footer, WhatsApp float, "Africa is calling" fixed-departure modal). |
| `package-classic-safari-falls.html` | **Package page** — The Classic Safari & Falls Experience. |
| `styles.css` / `script.js` | Shared theme, nav, reveals and scroll sequences (both pages). |
| `font-options.html` | Side-by-side hero in five alternative display faces (Playfair Display, Cinzel, Bodoni Moda, Marcellus, Fraunces). Not linked from the site. |

Homepage notes: destination-card buttons and Travel-Your-Way tiles pre-select the matching package filter; the modal shows once per browser session (sessionStorage) after 9 s; "View Itinerary" on the Classic Safari card links to `index.html`, the other packages are stubs. Testimonials are shortened from the reviews on the live site.

## Run it

Open `index.html` directly, or serve the folder:

```bash
npx serve .
```

## Design notes

- **Palette**: warm espresso ink for the cinematic chapters, alternating with parchment "sand" sections (`.light`) for the statement, route, itinerary, inclusions and inquiry. Brass gold accent throughout. Defined as CSS variables at the top of `styles.css`.
- **Type**: Cormorant Garamond (display) + Inter (UI) + Allura (the script "Safari" in the logo), loaded from Google Fonts.
- **Logo**: rebuilt as inline SVG from the supplied artwork (serif GoKo, copper script Safari, copper Africa outline). Generated by the `LOGO()` helper at the top of `script.js` into every `[data-logo]` slot (curtain, nav, footer); edit the path/text there to refine it.
- **Cinematic devices**: intro curtain, letterbox bars that retract on the hero, slow Ken Burns hero, film grain overlay, scroll-lit statement paragraph, count-up stats, reveal-on-scroll.
- **Scroll-linked sequences** (GSAP ScrollTrigger, loaded from cdnjs; all disabled under `prefers-reduced-motion` via the `.no-motion` class):
  1. *Hero film* — on landing, the GoKo mark (SVG, Africa outline draws itself) lifts and `assets/hero-dolly.mp4` autoplays (muted, ~20.3 s, motion-equalised): the camera glides out of the lodge, over the pool, across the bush to the waterhole and finishes on a close-up of the elephant. Four phrases surface and fade as the camera moves (`#filmCaptions` JSON in each page, timed as fractions of the film), then the title, lede and meta strip land in the final 1.6 s. "Skip intro" jumps to the end. The film is three Higgsfield generations stitched with ffmpeg: Kling v3.0 pro image-to-video from the hero still (`hero-dolly-part1.mp4`, 10 s) + two Seedance 2.5 forward extensions (`hero-dolly-ext.mp4` 8 s to the waterhole, `hero-dolly-ext2.mp4` 6 s into the close-up). If autoplay is blocked it falls back to the scroll-scrubbed frames in `assets/dolly/`, and on phones to the still.
     **Manual speed:** set `data-film-speed` on the hero section in each page (`1` = as encoded, `1.3` = 30 % faster, `0.8` = slower). It sets the video's playbackRate, so no re-encoding; captions and the title landing follow automatically. Browsers keep playback smooth roughly between 0.5 and 2.
     Re-stitch (1×): `ffmpeg -i assets/hero-dolly-part1.mp4 -i assets/hero-dolly-ext.mp4 -i assets/hero-dolly-ext2.mp4 -filter_complex "[0:v]scale=1920:1080,setsar=1,fps=24[a];[1:v]scale=1920:1080,setsar=1,fps=24[b];[2:v]scale=1920:1080,setsar=1,fps=24[c];[a][b][c]concat=n=3:v=1:a=0[v]" -map "[v]" -c:v libx264 -crf 16 src.mp4`
     Constant-speed remap: the three AI clips each ease in and out, so `tools/remap.js` measures frame-to-frame motion per second (ffmpeg tblend+signalstats), derives a per-second speed factor that flattens it (smoothed, clamped 0.7–2.2×, target 18 s), and re-times each second with minterpolate where it slows down. An `OVERRIDE` map at the top of the script pins specific source seconds to a chosen speed; the final push into the close-up (source seconds 20–23) is held to 0.95 / 0.7 / 0.5 / 0.5× so it does not rush. Run it in a folder containing `src.mp4`, `motion.json` and an `ffm/` ffmpeg-static install; it writes `remapped.mp4`, which becomes `assets/hero-dolly.mp4`.
     Re-extract frames: `ffmpeg -i assets/hero-dolly.mp4 -vf "fps=120/20.33,scale=1440:-2" -q:v 7 -frames:v 120 assets/dolly/frame_%03d.jpg`
  2. *Three Acts* — each photo unmasks bottom-to-top with a stagger, then the route line draws itself.
  3. *Falls chapter* — the pinned image crossfades between four scenes as each text block reaches centre (desktop only).
  4. *Kruger strip* — the gallery pins and scrolls sideways, captions sliding in per panel; falls back to a grid under 1100px.
  5. *Itinerary rail* — a gold line draws down the left as you scroll; each day’s dot and number light as the line passes.
  6. *Kosher card* — background parallaxes at a slower rate than the card, and the card’s gold border draws itself on entry.
  7. *Quote focus pull* — the backdrop settles from 1.18× to 1× while the text resolves from blur to sharp.
  8. *Inquiry* — deliberately static apart from the standard soft reveal.
- **Sections**: Hero → Statement → Three Acts (route) → Chapter One: Victoria Falls → Chapter Two: Greater Kruger (gallery) → Kosher & Shabbat → Day-by-day → Inclusions → Quote → Inquiry → Footer.

## Images

The hero (`assets/hero-lodge.jpg`, 2688×1520) was generated with Higgsfield (gpt_image_2, 2k/high) from the GoKo lodge-at-sunset brief and saved as JPEG at quality 86; the full-resolution PNG master (`assets/hero-lodge.png`) sits alongside it. All other photography is hot-linked from Unsplash for the mock-up. Replace with GoKo's own imagery before launch by swapping the `src` attributes (or drop files into `assets/` and point to them).

The **Chapter One (Victoria Falls)** panel currently uses a forest elephant image with an animated mist overlay because no waterfall shot was available. Swap it for a photograph of the Falls; the mist layer will sit on top of whatever image is used.

## Itinerary copy

The day-by-day is a *sample flow* derived from the original page's 1 / 3 / 5-night structure and listed activities. Lodge names were not on the original page, so none are named here.
